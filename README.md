# Ꚃ𝑜𝓊𝓁 Ꚃ𝑜𝒸𝒾𝑒𝓉𝓎 | ࣪ ִֶָ☾.

Phase 1 is a static, reusable Next.js App Router frontend. All visible content lives in `constants/content.ts` and every current page is already routed.

Future-ready contracts sit in `future/`; a Supabase adapter can implement `CommunityRepository` without changing the UI component API. Discord OAuth, live server data, storage uploads, ticket automation, and an admin workspace intentionally remain out of scope until Phase 2.

## Run locally

`npm install` then `npm run dev`
